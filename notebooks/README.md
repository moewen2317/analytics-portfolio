# Notebooks

Put the original Jupyter notebooks for each project in this folder, using these names so the links in the README work:

- `readmission-and-segmentation.ipynb`
- `coupon-acceptance.ipynb`
- `product-launch-success.ipynb`
- `gender-earnings-gap.ipynb`
- `airline-delays.ipynb`

Before you add a notebook, remove anything that identifies you as a student (student ID, cells that print file paths containing it) and clear any outputs you do not want public.
Datasets are not stored in this repository. The coupon data is public (UCI Machine Learning Repository); the others came with the coursework, so check the module's rules before sharing them.
